# CS-330
This project really helped me get better at taking a visual problem and breaking it down into smaller, easier-to-handle pieces. I figured out how to look at a flat reference image and spot the basic 3D shapes I could use to build it. Instead of making every object super complicated, I learned to use simple shapes like boxes, cylinders, spheres, planes, and cones and put them together to make recognizable objects. I also got a much better grasp of how scale, rotation, and translation change where objects sit in a 3D space.
While working on this project, I got a much clearer understanding of how to write modular C++ code. Rather than throwing all the code into one giant function, I split things up into different parts for scene management, camera management, loading textures, materials, lighting, and rendering. Having separate functions for loading textures and applying materials cut down on repeated code and made the whole program way easier to fix and update.
This project gave me real hands-on experience with ideas that mix programming, math, visualization, and how users interact with things. Working with X, Y, and Z coordinates made my understanding of 3D space way stronger. Transformations, camera movement, projection matrices, lighting, and materials showed me how math concepts can actually be used to create cool visual effects
